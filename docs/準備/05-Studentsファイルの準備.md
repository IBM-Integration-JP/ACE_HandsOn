# Studentsファイルの準備

① 「students.zip」を下記のリンクからダウンロードします。

[ダウンロード](../resources/students.zip)   

② ダウンロードしたファイルを、VM環境の「ダウンロード」フォルダーにコピーします。

![スクリーンショット](../images/準備/05-Studentsファイルの準備/1.png)

③ 「students.zip」を「C:\」に解凍します。

![スクリーンショット](../images/準備/05-Studentsファイルの準備/2.png)

![スクリーンショット](../images/準備/05-Studentsファイルの準備/3.png)

以上となります。
