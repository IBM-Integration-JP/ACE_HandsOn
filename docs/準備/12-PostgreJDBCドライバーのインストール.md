# PostgreSQL JDBCドライバーのインストール手順

① PostgreSQLの「スタックビルダ」ダイアログが起動していない場合には起動します。

- 「スタート・ボタン」 →「PostgreSQL 15」→「Application Stack Builder」を選択します。

![スクリーンショット](../images/準備/12-PostgreJDBCドライバーのインストール/1.png)

② 「スタックビルダ」のウィザードが開きます。ドロップダウンリストからインストールした「PostgreSQL 15」を選択し、「次へ」をクリックします。

![スクリーンショット](../images/準備/12-PostgreJDBCドライバーのインストール/2.png)

③ 「Database Drivers」→「pgJDBCv42.7.2-1」を選択し「次へ」をクリックします。

![スクリーンショット](../images/準備/12-PostgreJDBCドライバーのインストール/3.png)

④ ダウンロードディレクトリはデフォルトのままにして、「次へ」をクリックします。

![スクリーンショット](../images/準備/12-PostgreJDBCドライバーのインストール/4.png)

⑤ ダウンロード先ディレクトリに、「edb_pgjdbc」というファイル名のドライバーが正常にダウンロードできたことを確認します

![スクリーンショット](../images/準備/12-PostgreJDBCドライバーのインストール/5.png)

⑥ 「次へ」をクリックしてインストールを開始します。

![スクリーンショット](../images/準備/12-PostgreJDBCドライバーのインストール/6.png)

⑦ 「Setup pgJDBC」ウィザードが開きます。「Next」をクリックします。

![スクリーンショット](../images/準備/12-PostgreJDBCドライバーのインストール/7.png)

⑧ インストール先ディレクトリはデフォルトのままにし「Next」をクリックします。

![スクリーンショット](../images/準備/12-PostgreJDBCドライバーのインストール/8.png)

⑨ 「Next」をクリックします。

![スクリーンショット](../images/準備/12-PostgreJDBCドライバーのインストール/9.png)

⑩ インストールが完了したら、「Finish」をクリックします。

![スクリーンショット](../images/準備/12-PostgreJDBCドライバーのインストール/10.png)

⑪　「終了」をクリックし、スタックビルダを終了します。

![スクリーンショット](../images/準備/12-PostgreJDBCドライバーのインストール/11.png)

⑫ インストール先ディレクトリに「postgresql-42.7.2.jar」ファイルがあることを確認します。

![スクリーンショット](../images/準備/12-PostgreJDBCドライバーのインストール/12.png)

⑬ 続いて、ACE ツールキットに PostgreSQL 用の JDBC ドライバーを設定します。

- ツールキットが起動していない場合には起動します。
- 「スタート・ボタン」→「IBM App Connect Enterprise 13.0.6.0 Evaluation Edition」→「IBM App Connect Enterprise Toolkit 13.0.6.0」を選択します。
- ウィンドウ → 設定 をクリックします。

![スクリーンショット](../images/準備/12-PostgreJDBCドライバーのインストール/13.png)

⑭ 「ドライバー」で検索して、「ドライバー定義」を選択します。

![スクリーンショット](../images/準備/12-PostgreJDBCドライバーのインストール/14.png)

⑮ フィルターで「汎用 JDBC」を選択し、「汎用 JDBC 1.0」をクリックして「編集」をクリックします。

![スクリーンショット](../images/準備/12-PostgreJDBCドライバーのインストール/15.png)

⑯ 「JARリスト」にPostgreSQLのjarを追加します。

![スクリーンショット](../images/準備/12-PostgreJDBCドライバーのインストール/16.png)

⑰ 「プロパティー」の「ドライバー・クラス」が空になっているので、右側の「…」をクリックします。

![スクリーンショット](../images/準備/12-PostgreJDBCドライバーのインストール/17.png)

⑱ 「クラスの参照」で「org.postgresql.Driver」を選択し、「OK」をクリックします。

![スクリーンショット](../images/準備/12-PostgreJDBCドライバーのインストール/18.png)

 「OK」→「適用して閉じる」をクリックして、ドライバー定義の編集を終了します。

以上となります。
