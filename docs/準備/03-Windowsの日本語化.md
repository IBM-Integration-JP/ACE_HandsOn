# Windowsの日本語化設定手順

① 「Settings」を開きます。

![スクリーンショット](../images/準備/03-Windowsの日本語化/1.png)

②「Time & Language」を選択します。

![スクリーンショット](../images/準備/03-Windowsの日本語化/2.png)

③ 左側のメニューから「Language」を選択し「Preferred languages」から「Add a language」をクリックします。

![スクリーンショット](../images/準備/03-Windowsの日本語化/3.png)

④ 一覧から「日本語」を選択し「Next」をクリックします。

![スクリーンショット](../images/準備/03-Windowsの日本語化/4.png)

⑤ 下記の項目にチェックを入れ、インストールを進めます。

![スクリーンショット](../images/準備/03-Windowsの日本語化/5.png)

⑥ インストールが完了したら、一度サインアウトします。

![スクリーンショット](../images/準備/03-Windowsの日本語化/6.png)

⑦ 再度サインインし、日本語表示に切り替わっていることを確認します。   
「Settings」を開き、「時刻と言語」を選択します。

![スクリーンショット](../images/準備/03-Windowsの日本語化/7.png)

⑧ 「日付と時刻」を選択し、タイムゾーンを「日本標準時（UTC+09:00）」に設定します。

![スクリーンショット](../images/準備/03-Windowsの日本語化/8.png)

⑨ 左側のメニューから「地域」をクリックし、「国または地域」を「日本」に設定します。

![スクリーンショット](../images/準備/03-Windowsの日本語化/9.png)

⑩ キーボードレイアウトを日本語に変更します。   
左側のメニューから「言語」を選択し、「優先する言語」の一覧から「日本語」を選択して「オプション」をクリックします。

![スクリーンショット](../images/準備/03-Windowsの日本語化/10.png)

⑪ 「レイアウトを変更する」をクリックします。

![スクリーンショット](../images/準備/03-Windowsの日本語化/11.png)

⑫ 「日本語キーボード」を選択します。再起動して設定を反映させます。

![スクリーンショット](../images/準備/03-Windowsの日本語化/12.png)


以上となります。
